Overview

Built for real-time V2V awareness

Sensor fusion

Accelerometer, gyroscope, ultrasonic distance, and servo angle data are gathered in real time.

Low-latency network

ESP-NOW enables rapid communication between nearby cars for coordinated driving decisions.

Browser dashboard

The project includes a web UI served by the ESP32 access point, making it easy to inspect data.

Features

What the system does

Real-time sharing

Each vehicle broadcasts its current sensor state to nearby cars.

Obstacle detection

Ultrasonic distance measurement supports collision warnings and braking assistance.

Driver controls

Control the steering and motion from the browser to test driving behavior.

Dashboard analytics

Nearby cars and sensor states are surfaced in a clean monitoring interface.

Setup

How to run the project

  1. Flash the Arduino sketch in drivenet.ino onto an ESP32 board.
  2. Connect to the network named DriveNet_AP with password drivenet123.
  3. Open the local device page at http://192.168.4.1.
  4. Use the dashboard to monitor sensors and nearby vehicles.
