Setup

How to run the project

  1. Flash the Arduino sketch in drivenet.ino onto an ESP32 board.
  2. Connect to the network named DriveNet_AP with password drivenet123.
  3. Open the local device page at http://192.168.4.1.
  4. Use the dashboard to monitor sensors and nearby vehicles.
